# Plan: 会员照片完全随机散落

## Summary

去掉3×4网格分配，改为纯随机+碰撞检测算法。照片大小、位置、角度都随机，像散落在桌面上。

`closing_remark.html` 第351-400行：

## Proposed Changes

### 文件：`closing_remark.html`（第351-400行替换）

用纯随机+碰撞检测替换网格算法：

1. **去掉网格**：不再分配格子
2. **随机尺寸**：高度 10-22vh，宽度按比例

4. **碰撞检测**：200次尝试找不重叠位置，找不到则用最小重叠
5. **左右交替**：偶数在左(1-28vw)，奇数在右(67-99vw)
6. **纵向铺满**：2-95vh
