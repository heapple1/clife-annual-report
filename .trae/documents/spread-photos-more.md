# Plan: 照片更分散

## Summary

当前照片集中在两侧窄带里，需要拉宽 x 范围并增加碰撞间距，让照片在整个页面两侧更均匀散开。

## Current State Analysis

`closing_remark.html` 第 360-393 行的分布逻辑：

- 左侧 x 范围：5%VW ~ 22%VW（仅 17% 宽）
- 右侧 x 范围：75%VW ~ 95%VW（仅 20% 宽）
- 碰撞间距 pad：`hPx * 0.08`（很小，照片几乎贴在一起）
- 照片高度：10%-22%VH
- 24 张照片，左右各 12 张，挤在窄带里 → 视觉上太集中

九宫格居中，宽度约 65vmin。在 1920px 宽屏上，九宫格约占 37% 宽度，两侧各有约 31% 的可用空间。当前只用了其中 17%-20%，浪费了大量空间。

## Proposed Changes

**文件**：`closing_remark.html`，第 360-393 行

### 1. 拉宽 x 范围

```
// 旧值
var xMin=side===0?0.05*VW:0.75*VW;
var xMax=side===0?0.22*VW-wPx:0.95*VW-wPx;

// 新值
var xMin=side===0?0.02*VW:0.70*VW;
var xMax=side===0?0.30*VW-wPx:0.98*VW-wPx;
```

- 左侧：2% ~ 30%VW（28% 宽，比原来 17% 宽了近一倍）
- 右侧：70% ~ 98%VW（28% 宽，比原来 20% 宽了 40%）
- 仍然不贴边（留 2% 边距）也不贴九宫格（30% / 70% 在九宫格边界外）

### 2. 增大碰撞间距

```
// 旧值
var pad=Math.round(hPx*0.08);

// 新值
var pad=Math.round(hPx*0.35);
```

pad 从 8% 提到 35%，碰撞检测盒子大幅膨胀，迫使照片之间保持更大距离，自然散开。

### 3. 增加随机尝试次数

```
// 旧值
for(var t=0;t<200;t++){

// 新值
for(var t=0;t<400;t++){
```

范围变大后，200 次可能找不到零重叠解，提升到 400 次确保质量。

## Verification

刷新页面后，照片应在两侧各自约 28% 宽的区域内均匀散开，不再挤在窄带里，同时不贴边、不贴九宫格、照片之间不重叠。
